# GitHub First Push

一个用来走通「本地提交 → 推送到 GitHub」完整流程的练习仓库。

## 这是干什么的

2026-09-28，我刚刚把 GitHub 用户名改成 `jv0721`，顺手建了这个仓库来验证
本地 Git 环境是不是真的通了。

## 里面有什么

| 文件 | 说明 |
|---|---|
| `hello.py` | 一个最简单的 Python 脚本，运行后会打招呼并打印当前时间 |
| `.gitignore` | Python 项目常见的忽略规则，避免把垃圾文件提交上去 |

## 怎么跑

```bash
python hello.py
```

## 学到的东西

- `git init` 把普通文件夹变成 Git 仓库
- `git add` 把文件放进暂存区
- `git commit` 把暂存区存成一个版本快照
- `git push` 把本地提交上传到 GitHub
